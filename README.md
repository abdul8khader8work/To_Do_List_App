## 📱 Installation Guide (All Platforms)

This app is a **Progressive Web App (PWA)** — no app store needed! Install it directly from your browser.

### 🖥️ Windows

**Using Chrome / Edge:**
1. Open [to-do-list-app-seven-teal.vercel.app](https://to-do-list-app-seven-teal.vercel.app) in Chrome or Edge
2. Look for the **install icon** (⊕) in the address bar, OR click "Install Todo List" banner
3. Click **"Install"**
4. The app opens as a standalone desktop app with its own window and taskbar icon

**Using Firefox:**
1. Open the app URL
2. Click the menu (☰) → **"Install"** or **"Add to Desktop"**

### 🍎 macOS

**Using Safari:**
1. Open [to-do-list-app-seven-teal.vercel.app](https://to-do-list-app-seven-teal.vercel.app) in Safari
2. Click **File** → **"Add to Dock"** (macOS Sonoma+)
3. The app appears in your Dock and Launchpad

**Using Chrome:**
1. Open the app URL
2. Click the install icon in the address bar
3. Click **"Install"**

### 🐧 Linux

**Using Chrome / Chromium:**
1. Open [to-do-list-app-seven-teal.vercel.app](https://to-do-list-app-seven-teal.vercel.app)
2. Click the install icon (⊕) in the address bar
3. Click **"Install"**
4. The app appears in your application menu

**Using Firefox:**
1. Open the app URL
2. Click the menu (☰) → **"Install"**

### 📱 Android

1. Open [to-do-list-app-seven-teal.vercel.app](https://to-do-list-app-seven-teal.vercel.app) in **Chrome**
2. Tap the **menu** (⋮) in the top-right
3. Tap **"Install app"** or **"Add to Home screen"**
4. Tap **"Install"**
5. The app icon appears on your home screen — works like a native app!

### 🍏 iOS (iPhone / iPad)

1. Open [to-do-list-app-seven-teal.vercel.app](https://to-do-list-app-seven-teal.vercel.app) in **Safari**
2. Tap the **Share** button (□↑) at the bottom
3. Scroll down and tap **"Add to Home Screen"**
4. Tap **"Add"**
5. The app icon appears on your home screen

## 🔨 Building Desktop & Mobile Apps Locally

If you want to build the apps yourself:

### Desktop Apps (Windows, macOS, Linux)

```bash
# Build the web app
npm run build

# Build for your platform
npx electron-builder --win --config electron-builder.json
npx electron-builder --mac --config electron-builder.json
npx electron-builder --linux --config electron-builder.json
```

### Android APK

```bash
# Build the web app
npm run build

# Generate the Android project (once per checkout)
npx cap add android

# Sync and build
npx cap sync android
cd android
gradlew.bat assembleDebug # Windows
# ./gradlew assembleDebug # macOS/Linux
```

The APK will be at: `android/app/build/outputs/apk/debug/app-debug.apk`

## 🚀 Automated Builds

This project uses GitHub Actions to build all desktop and Android artifacts in one run when a version tag is pushed. The release is published only after all four builds succeed.

**To trigger a build:**
```bash
# Create and push a tag
git tag v1.0.0
git push origin v1.0.0
```

This will automatically:
1. Build Windows .exe, macOS .dmg, Linux .AppImage
2. Build Android APK
3. Create a GitHub Release with all artifacts attached
