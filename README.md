## 📱 Installation Guide (All Platforms)

This app is a **Progressive Web App (PWA)** — no app store needed! Install it directly from your browser.

### 🖥️ Windows

**Using Chrome / Edge:**
1. Open the app URL in Chrome or Edge
2. Look for the **install icon** (⊕) in the address bar, OR click "Install Todo List" banner
3. Click **"Install"**
4. The app opens as a standalone desktop app with its own window and taskbar icon

**Using Firefox:**
1. Open the app URL
2. Click the menu (☰) → **"Install"** or **"Add to Desktop"**

### 🍎 macOS

**Using Safari:**
1. Open the app URL in Safari
2. Click **File** → **"Add to Dock"** (macOS Sonoma+)
3. The app appears in your Dock and Launchpad

**Using Chrome:**
1. Open the app URL
2. Click the install icon in the address bar
3. Click **"Install"**

### 🐧 Linux

**Using Chrome / Chromium:**
1. Open the app URL
2. Click the install icon (⊕) in the address bar
3. Click **"Install"**
4. The app appears in your application menu

**Using Firefox:**
1. Open the app URL
2. Click the menu (☰) → **"Install"**

### 📱 Android

1. Open the app URL in **Chrome**
2. Tap the **menu** (⋮) in the top-right
3. Tap **"Install app"** or **"Add to Home screen"**
4. Tap **"Install"**
5. The app icon appears on your home screen — works like a native app!

### 🍏 iOS (iPhone / iPad)

1. Open the app URL in **Safari**
2. Tap the **Share** button (□↑) at the bottom
3. Scroll down and tap **"Add to Home Screen"**
4. Tap **"Add"**
5. The app icon appears on your home screen

## 🚀 Local Development

```bash

cd todo-list-app

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 🌍 Deploy Your Own

This app is deployed on **Vercel** (free). You can deploy your own copy:

### Option 1: Vercel (Recommended)
1. Fork this repo
2. Go to [vercel.com](https://vercel.com)
3. Import your forked repo
4. Click **Deploy** — done!

### Option 2: Netlify
1. Fork this repo
2. Go to [netlify.com](https://netlify.com)
3. Connect your GitHub
4. Select the repo and deploy

### Option 3: GitHub Pages
1. Fork this repo
2. Install `gh-pages`: `npm install -D gh-pages`
3. Add deploy script and run `npm run deploy`
4. Enable GitHub Pages in repo settings
